## 第二层：Polymarket 市场结构

目标：理解订单不是简单“买卖”，而是链下 CLOB、签名订单、Operator、Relayer 和链上结算共同组成。

已经学过：

- 签名订单不是最终成交。
- Maker / Taker 在费用和延迟上不同。
- `p * (1 - p)` Taker fee 会吞掉小 edge。
- Split / Merge / Redeem 会影响真实 PnL。

项目里已经落实：

- `gross_edge` / `net_edge` 分离。
- 回测里加入 Taker fee、滑点和安全边际。

下一步要落实：

- paper order 状态机。
- API 错误分类。
- 本地行情缓存。
