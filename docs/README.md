# Ploymarket Docs

这个目录用于记录项目之外的学习、复盘和系统状态。下次重新打开项目时，建议先按这个顺序读：

1. [当前系统状态](system/current-state.md)
2. [学习进度记录](learning/progress-log.md)
3. [模拟盘运行手册](runbooks/paper-trading.md)
4. [风控学习笔记](strategy/risk-control-basics.md)
5. [Polymarket 底层机制知识库](strategy/polymarket-market-structure.md)
6. [项目路线图](system/roadmap.md)

## 目录说明

- `learning/`: 每次学习和讨论后的进度记录，帮助我们接上上下文。
- `system/`: 当前系统已经实现的功能、限制和下一步架构方向。
- `runbooks/`: 具体怎么运行、检查、排错。
- `strategy/`: 策略、风控、回测方法和交易理解笔记。
- `records/`: 每次模拟盘或策略实验的记录模板。

## 使用习惯

每次有明显进展后，更新两类文档：

- `learning/progress-log.md`: 记录这次学了什么、做了什么、下次从哪里继续。
- `system/current-state.md`: 如果系统功能发生变化，更新当前功能和限制。

如果只是一次实验结果，优先在 `records/` 里新增一份记录。
