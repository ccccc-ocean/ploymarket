# 风控学习笔记

## 为什么先学风控

自动化交易最危险的地方不是策略错一次，而是策略错了以后还能继续高速执行。风控的作用是让系统在不确定、故障和连续亏损时自动降速或停机。

我们的长期目标是实盘盈利，所以第一阶段先建立一个习惯：

每个策略信号都必须经过风控层，策略本身不能直接下单。

## 当前风控参数怎么理解

### `starting_cash`

模拟盘本金。它不是收益目标，而是用于计算仓位、亏损和回撤的基准。

建议：

- 第一轮用 `1000` USDC 这样的整数，方便理解。
- 如果未来实盘本金是 5000 USDC，可以先用 1000 USDC 模拟。

### `max_position_usdc`

单笔最大投入。

如果设为 `50`，代表任何单笔交易最多投入 50 USDC。预测市场 YES token 理论最大亏损接近投入本金，所以这也是单笔最大亏损的近似上限。

建议：

- 保守：本金的 `1%-2%`。
- 普通模拟：本金的 `2%-5%`。
- 不建议第一阶段超过 `5%`。

### `max_market_exposure_usdc`

单个市场最大敞口。

比如同一个 BTC 月内价格市场可能有很多相关问题，如果全部押同一方向，实际风险会集中。这个参数限制单个市场占用资金。

### `max_total_exposure_usdc`

所有持仓加起来的最大投入。

这个参数防止系统同时开太多仓，导致账户看起来每笔都小，但总体暴露很大。

### `daily_loss_limit_usdc`

日内亏损上限。

当当天已实现亏损达到这个值，系统停止新开仓。它保护我们免受连续错误、行情切换和程序异常的影响。

建议：

- 第一阶段设为本金的 `3%-5%`。
- 触发后当天不再开新仓，只复盘。

### `max_drawdown_pct`

账户从高点回撤的最大比例。

如果本金从 1000 涨到 1100，又跌到 970，回撤按高点 1100 计算，而不是初始本金。这比单纯看亏损更贴近实盘感受。

### `readiness_max_drawdown_pct`

模拟盘进入“候选可观察”状态的最大回撤阈值。

它不是实盘开关，也不会自动下单。当前设置为 `10%`，含义是：只要系统仍在模拟盘，允许策略继续观察略高于 8% 的回撤，但实盘前仍要额外检查链路健康、样本量、手续费占比和近期回撤是否收敛。

### `stop_loss_pct`

单笔止损比例。

预测市场价格经常跳动，止损太紧会被噪音洗掉，止损太松会让小错误变成大亏损。

当前从 `25%` 收紧到 `20%`，目的是减少单笔错误方向对总回撤的拖累。

### `take_profit_pct`

单笔止盈比例。

止盈不是为了“赚够就跑”这么简单，而是为了避免概率型资产回吐过多。当前模拟盘使用分批止盈：先在较低浮盈阈值卖出一部分，把利润落袋，剩余仓位继续观察。

当前分批止盈从 `12.5%` 卖出 `50%` 调整为 `16%` 卖出 `35%`，全量保护性止盈从 `25%` 调整为 `32%`，目的是让赢家多跑一段，降低频繁止盈/再入场带来的手续费磨损。

### `trailing_stop_activation_pct`

移动止盈启动阈值。

当仓位已经有明显浮盈后，系统开始记录峰值收益。如果之后从峰值回吐超过 `trailing_stop_drawdown_pct`，就卖出剩余仓位，避免一笔好交易变成普通甚至亏损交易。

当前移动止盈从 `12%` 启动、`6%` 回吐退出，调整为 `18%` 启动、`7%` 回吐退出，减少小波动把好仓位洗出去的概率。

### `max_spread`

最大买卖价差。

价差大说明流动性差。流动性差时，回测里的价格可能看起来能成交，实盘却买贵、卖不掉。

## 每次复盘问自己

- 这笔交易亏损是方向错、入场晚、止损问题，还是市场流动性问题？
- 如果连续出现 3 笔类似亏损，系统是否应该自动暂停？
- 当前单笔仓位让我心理上能否接受？
- 如果凌晨无人盯盘，这套规则会不会做出我醒来后无法接受的事？

## 进入实盘前的最低要求

- 模拟盘连续运行至少数周。
- 最大回撤低于心理可接受范围。
- 每笔交易都能解释入场和退出。
- 能明确知道策略在哪些市场不该交易。
- 小资金实盘测试只验证执行和滑点，不追求赚钱。
